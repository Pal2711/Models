## 📌 About The Project

The **Models Booking System** is a Python-based web application that allows users to browse models and book appointments online.
It includes a fully functional **Admin Panel** and a dedicated **Model Panel** for better system management.

### 🚀 Key Highlights

* Built with **Python (Django)**
* Secure user & model authentication
* Responsive UI using HTML, CSS, Bootstrap
* Admin & Model dashboards
* Role-based access control
* MySQL / SQLite database support
* Email notifications for bookings
